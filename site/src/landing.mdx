## Work with the model you have

Zincite shares a source-preserving parser across its commands. Formatting keeps
comments and identifier spelling. Linting reports rules with source locations.
Queries inspect declarations and data without running a solver.

<CardGrid>
  <LinkCard title="Format" description="Write consistent layouts, check a project or format an editor buffer." href="./guides/formatting/" />

Use a current stable Rust toolchain. The packages on crates.io are name
reservations; install the working commands from a checkout.

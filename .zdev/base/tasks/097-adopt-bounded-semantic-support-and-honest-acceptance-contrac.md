The brief, thesis mapping and open acceptance tasks promise a useful bounded semantic front end, explicitly accept documented exclusions without counting Limited outcomes as Completed, and retain complete syntax, processing and performance obligations.

## Context

The user requested research on Clippy, Ruff/ty and Shackle, then a bounded MiniZinc plan allowing semantic gaps. Read brief Semantic analysis, Interpretation before policy, Coverage and acceptance, Completion evidence, Query and data transformation expansion and Testing; background/thesis-rule-coverage.md; docs/callable-analysis-plan.md; and open base-083, base-050 and base-092. ## Boundaries

- Promise scoped identity, include/source ownership, common structural types, nominal enums, par/var, optionality and supported first-order overload/substitution facts. Preserve unique-selection and ambiguity vetoes. Keep existing bounded numeric, guarded, optional, iteration, definition and search proof owners and successful cases. No compiler invocation for ordinary linting, arbitrary evaluation, recursive execution, relation inversion, exhaustive library-body interpretation, flattening, solving, general certainty framework or new semantic crate.
- Distinguish supported-but-unproved facts, deliberately excluded semantic operations, missing or incorrect promised support, and actual input/dependency failures. Exclusions that block a selected rule remain located limitations and Limited. Acceptance can accept an explicitly documented exclusion, but cannot count it as Completed. Resource cutoffs, missing observations, crashes, invalid target syntax and promised-scope bugs cannot become exclusions to improve totals. Preserve CLI exits, exact rule IDs, source/suppression and safe-fix contracts.
- This bundle explicitly proposes best-effort acceptance for the two named wedding reductions: retain their incomplete status and refuse in-place writes while computed dependencies remain unresolved. Amend base-092 to require compiler checks and direct data checks on those previews plus a separate small complete structured-reduction example through both command forms exercising the complete write path. Do not require general enum-expression evaluation, and do not mark base-092 complete in this task. The real installed-library query resource failure remains a required repair.
- Documentation and coordinator-owned record changes only. Preserve completed records and all private evidence. Do not run Rust repairs, new tests, compiler controls or corpus sweeps. TASKS.md is generated. Do not import speculative semantic repairs; a later repair needs a concrete promised-scope witness and bounded task.
